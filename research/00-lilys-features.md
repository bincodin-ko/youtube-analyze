## 2. 릴리스 핵심 정체성
- "AI 리서치 도구": 유튜브·PDF·웹·음성·문서를 넣으면 **리포트(요약)** 를 만들고, **출처 번호로 원문 위치를 확인**하고, **Lily(AI 채팅)** 로 질문한다.
- 2023-11 유튜브 요약으로 시작 → 2025-10 누적 100만 명 → 홈페이지 기준 120만+ 사용자. YC 배지.
- 2026-01-14 UI 전면 개편, 2026-03-31 프로젝트 화면 개편으로 지금 구조("요약/확장")가 됨.

## 3. 입력 종류
- 유튜브 링크(일반·일부공개·재생목록·최대 30시간, 한 번에 최대 10개 입력, 동시 요약 3개)
- 영상/음성 파일, 실시간 녹음(회의록)
- PDF·DOCX·PPT(구형 .ppt 포함)·Markdown·이미지(JPG/PNG)
- 웹페이지 URL, 텍스트 붙여넣기
- X.com 영상 트윗, 팟캐스트, 링크드인 영상
- 책 제목/저자로 책 요약(2026-04)
- 크롬 확장: 유튜브 목록 위 "영상 인사이트 얻기" 버튼, 뉴스·논문·일반 웹에서도 동작
- 모바일 앱(Android 2026-03, iOS 2026-04): 유튜브 앱 "공유"로 보내기

## 4. 화면 구성 (2026 개편 후)

### 4-1. 홈
- 가운데 **"새로 추가하기"** 버튼(누르면 자료 종류 선택 창: 유튜브·PDF 등) → 링크 붙여넣기 → **"프로젝트 생성"** 버튼
- NOW(관심사 기반 추천 피드), 구독(유튜브·RSS 채널), 최근 프로젝트, 홈 하단 추천 콘텐츠
- 오른쪽 아래 고정 도움말 버튼(요금제·도움말 센터·새로운 기능·채용·앰배서더)

### 4-2. 왼쪽 사이드바
- 로고 / **새로 추가하기** / 홈 / **라이브러리**(정렬 버튼, 컬렉션=폴더, 하위 컬렉션, 드래그로 이동) / 구독 / **NOW** / **하이라이트**(모아보기, 날짜·리포트별 정렬) / 검색 / 설정 / 도움말·커뮤니티 / 로그인

### 4-3. 결과(프로젝트) 화면 — 3단
| 영역 | 내용 |
|---|---|
| **왼쪽: 자료(원본) 뷰어** | "자료 추가" · "자료 찾기"(키워드로 웹·유튜브·논문 검색 후 추가) 버튼, 영상 플레이어(채널 이름·구독 버튼·날짜), 아래 **스크립트** 전문(줄마다 숫자=타임스탬프, 클릭하면 그 구간 재생), 상단 **번역**(언어·페이지 선택). PDF면 원문 PDF + 페이지 하이라이트. 버튼으로 열고 닫음 |
| **가운데: 리포트** | 상단 **"요약" / "확장"** 탭, 리포트 종류 칩(기본 등), "노트 컨트롤러 열기"(길이·난이도·범위 조절), 공유, […] 메뉴(찾기·바꾸기, 설정 톱니바퀴 → 수정 모드), 모델 표시(일반모델/고급모델), 리포트 페이지 넘김(예: "< 2/2 >") |
| **오른쪽: 채팅 패널** | 탭 **"LILY"**(채팅) / **"하이라이트"**, 입력창 + 파일 첨부 + 보내기, 안내 문구(자료를 근거로 답변), 우측 상단 화살표로 열고 닫음 |

### 4-4. 리포트(기본 요약) 본문 형식 (공개 예시에서 직접 확인)
1. 제목 + "edited by"
2. **목차**(1. / 1.1. 2단 번호, 클릭하면 이동)
3. 3~4문장 **한 문단 총평**
4. 본문: `번호. 소제목 [n]` → 짧은 문장 여러 줄, **문장 끝마다 파란 출처 번호 [n]**(스크립트 줄 번호). "굵은 키워드: 설명" 형식이 섞임
5. 영상의 관련 캡처 이미지와 인포그래픽이 문단 사이에 들어감(영상 설명, 무료는 스크린샷 최대 2개)
6. 끝에 "공유 & 내보내기 & 복사할 수 있어요" 안내

### 4-5. 개편 전(2024) 탭 — 참고
요약노트 · 블로그글 · 스크립트 · 타임스탬프 · 채팅(네이트 뉴스 2024-12). 지금은 블로그·스크립트·타임스탐프가 "확장" 템플릿 안으로 들어감.

## 5. 기능 전체 목록

### 5-1. 리포트(요약)
- 요약 탭: **기본 / 짧게 / 길게 / 쉽게**, 노트 컨트롤러로 길이·난이도·범위 조절, 기본 리포트 지정
- 확장 탭(30여 템플릿, 2025-10에 31종):
  - 나만의 템플릿(이름 + 프롬프트 저장 → 클릭 한 번으로 재사용. 영상에선 "블로그" 템플릿을 이렇게 만듦)
  - 더 깊이 이해하기: 배경지식, 반대 시각 조사, 액션아이템 도출, 심층 노트(2025-12)
  - 시각 자료: **마인드맵**, 인포그래픽(스타일: 컬러풀·과학적·손글씨·미니멀·기업용 등), 카툰, 애니메이션(2026-01), 다이어그램
  - 이해 점검: 플래시카드(출처 포함), 퀴즈, 교재, 팟캐스트(대화형)
  - 그 외: 스크립트, 블로그, 타임스탐프, 회의록, 투자종목 분석, 논문 리뷰, 문헌 검토, 중요 인용구/인용노트(QuoteNote), 유튜브 댓글 분석(통계·감정·주요 의견, 2026-01)
  - 주제 자동 분류 후 템플릿 추천(2025-07)
- **PPT 만들기**(2026-08): 확장 리포트에서 9가지 디자인, 2~30장, PPTX 다운로드
- 멀티 자료: 한 페이지에 자료 여러 개(무료 10개, 유료 20개) 묶어 통합 요약 + 자료별 리뷰
- 여러 노트 동시 생성, 타임라인 요약 5초 안에 시작

### 5-2. 읽기·확인
- **출처확인**: 문장 끝 [n] 파란 번호 → 마우스 올리면 원문 미리보기, 클릭하면 왼쪽 뷰어 해당 원문으로 이동
- **타임스탬프**: 스크립트 숫자 클릭 → 그 구간 재생
- **해설**: 문장 클릭 → "해설" → 쉬운 설명, 이어서 Lily와 대화
- **하이라이트 & 메모**(드래그), 하이라이트 모아보기
- 선택한 부분을 Lily에게 질문(2025-07)
- 변경 사항 보기(추가·삭제·수정 강조, 2025-09)
- 자료 원문 번역(영상·음성 스크립트, PDF 원문 — 표 유지)

### 5-3. 편집
- 수정 모드: 굵게·기울임·밑줄·링크·색상, H1~H3, 글머리·번호 목록, 토글, 인용구
- 제목 클릭해 변경, 찾기·바꾸기(Ctrl+F)
- Lily에게 전체/선택 부분 수정 요청(수정 부분 하이라이트)
- 스크립트 편집(찾아 바꾸기, 2026-08)
- Lily 명령으로 "관련 스크린샷 캡처해서 추가", "적절한 도표·그래프 추가"(2025-07)

### 5-4. 채팅(Lily)
- 자료 근거 답변(Gemini 최신 모델 표시), 횟수 무제한(무료 포함)

### 5-5. 보관·관리

## 7. 사용 흐름 (영상 2개 + 도움말 기준)
1. 홈 → **새로 추가하기** → 자료 종류(유튜브) 선택 → 링크 붙여넣기(최대 10개) → **프로젝트 생성**
2. 몇 초~수십 초 대기(타임라인 요약은 약 5초 만에 시작) → 결과 화면 자동 이동
3. 가운데 **요약 리포트**(목차 + 총평 + 소제목별 문장 + 캡처·인포그래픽) 읽기 → [n] 눌러 왼쪽 스크립트·영상 구간 확인
4. 위쪽 메뉴에서 **짧게/길게/쉽게**로 다시 생성
5. **확장** 탭(요약 탭 오른쪽)에서 마인드맵·인포그래픽·퀴즈 등 추가, 또는 나만의 템플릿(블로그) 추가
6. 오른쪽 **LILY** 채팅에서 "세 줄로 정리해줘" 같은 질문
7. 공유·내보내기·복사 → 홈 사이드바 **라이브러리**에서 다시 찾기(검색 아이콘)

## 8. FEATURES.md에 빠진 릴리스 기능

### 8-1. 첫 버전에 넣기를 제안 (화면 모방·사용감에 직결, 로컬·무료로 가능)
1. **문장별 출처 번호 [n] + 마우스 올리면 원문 미리보기 + 클릭 시 왼쪽 스크립트·영상 이동** — E1(타임스탬프)보다 촘촘한, 릴리스 리포트의 핵심 형식
2. **리포트 목차(TOC)** 와 클릭 이동, 맨 위 **한 문단 총평**
3. **요약 길이·난이도 바꾸기: 짧게 / 기본 / 길게 / 쉽게** (요약 탭 안 칩)
4. **"요약 / 확장" 2단 탭 구조** — 확장 안에 마인드맵·스크립트·타임스탬프·블로그를 넣는 현재 릴리스 배치
5. **해설**: 문장 클릭 → 쉬운 설명(C4 용어 풀이를 "필요할 때 클릭" 방식으로)
6. **드래그 선택 → 채팅에 질문/수정 요청**
7. **하이라이트 & 메모**와 사이드바 "하이라이트" 모아보기
8. **전체 복사 버튼**, 찾기(Ctrl+F)
9. **나만의 템플릿**(이름 + 프롬프트 저장) — FEATURES "요약 템플릿 여러 개"(다음 단계)를 가장 싼 방법으로 당겨옴
10. 왼쪽 원본 뷰어 **열기/닫기**, 오른쪽 채팅 패널 **열기/닫기**(E2를 3단 배치로 구체화)
11. 여러 링크 한 번에 넣기(대기열) — 개인용이라도 편함
