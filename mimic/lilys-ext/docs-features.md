# 릴리스 공식 문서·실제 화면에서 본 기능 (2026-10-12 크롬으로 확인)

출처: help.lilys.ai 「주요 템플릿 가이드」(articles/11811069), 「릴리즈노트」(articles/11782109)

## 확장 리포트 추가 창 (실제 화면 텍스트, YC 영상 노트)
- 추천: 중요 인용구 · 내 액션아이템 도출 · 관련 배경지식 · 인포그래픽
- 나만의 템플릿: ⚙ · + 만들기
- 더 깊이 이해하기: 관련 배경지식 · 반대 시각 조사 · 내 액션아이템 도출 · 댓글분석
- 시각자료: PPT(NEW) · 마인드맵(이미 있으면 흐림) · 인포그래픽 · 카툰 · 애니메이션
- 이해 점검하기: 플래시카드 · 퀴즈 · 팟캐스트
- (접기) 스크립트 · 타임스탬프 · 교재 · 보고서 · 회의록 · 사용자 인터뷰 · 문헌검토 · 투자 종목 분석 · 투자 방법론 · 논문 리뷰 · 중요 인용구 · 블로그 · 말씀
- 카드마다 ☆ 즐겨찾기, 여러 개 선택 → 하단 「N개 추가」/「취소」
- 창에 없는 것: 심화조사(실제 노트에 「심화조사」 있음 → 리포트 아래 「확장」 추천 「자료를 바탕으로 추가 리서치 수행」으로 생성되는 것으로 추정)

## 문서 설명
- 배경지식: 핵심 인물·사건·개념의 배경지식을 자동 조사
- 반대 시각 조사: 상반된 관점으로 균형 잡힌 시각
- 심화조사 노트: 자료와 연결된 추가 리서치(2025-12-11)
- 인포그래픽: 다양한 스타일(원페이저, 과학, 손글씨 ..) / 2026-09-07 새 이미지 엔진
- 카툰: 다양한 스타일(웹툰, 애니, 디즈니 등)
- 애니메이션: 핵심 내용을 애니메이션 형식으로(2026-01-21)
- PPT(2026-08-27): 미니멀·매거진·논문·도식·볼드 등 9가지 스타일, 2~30장, 장별 다시 생성, PPTX 다운로드
- 팟캐스트: 대화 형식으로 변환
- 댓글분석 템플릿(2026-01-11)
- 플래시카드: 정답에 출처 연결
- 즐겨찾기 ☆ → 확장 탭 상단에 표시

## 실제 리포트에서 본 동작 (OpenDesign 웹 노트)
- 관련 배경지식: 소제목마다 AI 그림 1장 + 본문 + 출처 도메인 칩(au.linkedin.com)
- 반대 시각 조사: 도입(원본 주장 요약) → 번호 소제목 3개, 문단 끝마다 출처 도메인 칩(facebook.com, rasmussen.edu)
- 심화조사: 1. 서론 / 2. 추가 리서치 주제(질문 3개) / 3. 추가 리서치 자료 목록
- 인포그래픽: 1024×1536 세로 이미지, 우상단 확대 버튼, 좌하단 버튼 2개(고급 이미지 모델=업그레이드 창, 이미지 다운로드)
- 모든 리포트 하단: 👍 👎 ↻(다시 만들기) 「일반모델」 · Notion · Slack · 공유 · 다운로드 · 복사 / 그 아래 「💡 확장」 추천 3줄(관련 배경지식 심층 탐색 · 자료를 바탕으로 추가 리서치 수행 · 반대 시각으로 균형 있게 이해)
- 목차(접힘 가능) + 오른쪽 가장자리 미니 목차 줄
- 마인드맵: markmap, 핵심어 굵게, 노드 끝에 숫자, 하단 줄 「다시 생성 · 다운로드 · 전체화면 · + · −」, 좌상단 ⓘ, 우상단 🗑
