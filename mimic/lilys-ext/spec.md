1. 그림 엔진 — 릴리스: 클라우드 이미지 AI(한글 글자도 그림 안에) / 우리: 로컬 FLUX.2 klein 4B(한글 글자 못 그림), 무료 조건 / 제안: 인포그래픽·PPT·요약 도식은 지금처럼 글자를 HTML로 그리고 스타일 테마를 입힘(한글 깨짐 없음). 카툰은 FLUX 그림 + HTML 말풍선 유지, 그림체만 스타일별로.
2. 웹 출처 — 릴리스: 서버가 웹 검색 / 우리: claude -p 도구 없음 / 제안: 배경지식·반대 시각·심화조사만 `--tools WebSearch,WebFetch` 허용(읽기만), 출처 URL을 칩으로.
3. 즐겨찾기 저장 — 릴리스: 계정 / 우리: localStorage인데 앱이 사생활 모드라 재시작 때 지워짐 / 제안: [기존 변경] app.pyw private_mode=False + data/webview 저장 폴더.
4. Notion·Slack·아카이브 — 릴리스: 외부 계정 연동 / 우리: 로그인 금지 / 제안: Notion·Slack 빼고(CHANGES 기록), 아카이브는 「컬렉션 지정」으로 연결.
5. 리포트 주소 — 릴리스: 리포트마다 URL / 우리: 탭 상태 / 제안: `?ext=키`로 새로고침해도 같은 리포트.

## 1묶음
### A. 인포그래픽 스타일 선택 (#10~12, #15)
1. 추가 창에서 인포그래픽을 골라 「추가」 → 바로 만들지 않고 「인포그래픽 스타일 선택」 창. [자동]
2. 스타일 6개(원페이저·컬러풀·과학적·손글씨·미니멀·기업용)+한 줄 설명, 2줄×3칸, 기본 원페이저 ✓. [자동][화면]
3. 스타일을 누르면 ✓ 이동 + 「미리보기」 견본 바뀜(견본은 시험 데이터로 우리가 그린 그림). [자동]
4. 「고급 설정」 → 「추가 프롬프트 (선택사항)」 칸, 적은 내용은 생성 지시에 덧붙음. [자동]
5. 「만들기」 → 창 닫히고 "만드는 중" 상자+진행 막대. 취소·X·Esc는 아무것도 안 만듦. [자동]
6. 결과는 고른 스타일의 글꼴·색·모양(손글씨=손글씨 글꼴·파스텔·스케치 테두리 등). 스타일은 저장돼 새로고침해도 같음. [자동: data-style][화면]
7. 기존 레이아웃 5종 전환·PNG·[n] 재생은 그대로. [자동]
### B. 카툰 스타일 선택 (#13, #14)
1. 카툰 추가 → 「만화 스타일 선택」: 웹툰·사실적·일본 애니·치비·디즈니·코믹북(+설명), 기본 웹툰, 미리보기, 고급 설정. [자동][화면]
2. 고른 스타일이 칸마다 그림 지시에 붙음. 칸별 다시 그리기도 같은 스타일. [자동: 저장 style·지시문][직접: 그림체 눈 확인]
3. 기존 격자·말풍선·[n]·PNG 그대로. [자동]
### C. 배경지식·반대 시각·심화조사 웹 출처 (#27~29)
1. 「관련 배경지식」「반대 시각 조사」는 웹 검색 후 bullet마다 출처가 있으면 끝에 회색 칩(도메인). 칩 누르면 그 페이지가 기본 브라우저로 열림. [자동: 칩 href][--online 실제 생성 1회]
2. 반대 시각 조사: "원본 주장 요약" 도입 → 번호 소제목 3개. [자동]
3. 새 템플릿 「심화조사」: 1. 서론 / 2. 추가 리서치 주제(질문 3개) / 3. 추가 리서치 자료 목록(제목+링크). 웹 글 노트의 추천 칸에 보임. [자동]
4. 웹 검색 실패 시 출처 없이 만들고 맨 위 "웹 검색 없이 만들었어요". [자동]
5. 소제목 AI 그림(#28)은 이번에 안 넣음(질문 4).
### D. 리포트 아래 피드백 줄 + 「💡 확장」 추천 (#24~26)
1. 확장 리포트와 요약 맨 아래: 👍 👎 ↻ · 공유 · 다운로드 · 복사. 👍👎 상태 저장(새로고침 유지). [자동]
2. ↻ → 확인 창("다시 만들까요? 지금 결과는 사라져요") → 다시 만듦. [자동]
3. 그 아래 「💡 확장」 + 아직 안 만든 템플릿 추천 3줄(자료 종류별 순서). 누르면 바로 생성 (추측: 릴리스 미확인). [자동]
4. 「아카이브로 이동」 대신 「컬렉션 지정」. [자동]
