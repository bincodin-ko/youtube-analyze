## B. 받아들인 한계

- [verify] 화면 시나리오는 외부 주소(유튜브 등)를 막고 돌려 유튜브 플레이어 자리는 검은 칸. 채팅 전송·리포트 생성 같은 AI 동작은 결정적이지 않아 verify에 넣지 않음.
- [내 파일] 내 영상·음성 원본은 data/uploads/<id>/에 남김(노트 삭제 시 같이 지움). PDF는 글자가 든 것만(pypdf, 스캔본·OCR 없음, 이미지·표 모양 미가져옴; PyMuPDF는 AGPL이라 금지).
- [웹 글] 로그인·유료·JS로만 그려지는 페이지는 본문 추출 실패 안내로 끝남(로그인 없이 읽는 방법 없음).
- [번역] 긴 영상은 문단 묶음이 순차 호출이라 느림. 번역 중 페이지를 떠나도 서버는 계속 돌아 저장함.
- YouTube 정책상 다운로드 금지 → 개인용이라 720p 받아 캡처 후 즉시 삭제로 감수(상업화 시 재검토).
- 릴리스에 다크 모드 없음 → 우리가 새로 설계.
- [데스크톱 앱] 아이콘을 두 번 누르면 창이 하나 더 열림(같은 서버 공유, 사용자가 좋다고 해서 그대로).
- [마인드맵 v2] 모바일에선 맞춤 화면 글자가 5px 안팎이라 손가락 확대·드래그 필요. PNG 다운로드는 시스템 글꼴.
