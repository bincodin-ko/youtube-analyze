# 영상노트 보내기 (크롬 확장)

보고 있는 유튜브 영상이나 웹 글을 내 컴퓨터의 영상노트로 보내고, 영상의 원하는 구간을 스크랩합니다.
데이터는 내 컴퓨터(127.0.0.1)로만 갑니다.

## 설치 (직접 한 번만)
1. 영상노트를 켭니다(바탕화면 아이콘).
2. 크롬 주소창에 `chrome://extensions` 를 입력해 엽니다.
3. 오른쪽 위 "개발자 모드"를 켭니다.
4. "압축해제된 확장 프로그램을 로드합니다"를 누릅니다.
5. 이 `extension` 폴더를 선택합니다.
6. (선택) 퍼즐 모양 버튼에서 "영상노트 보내기"를 고정해 두면 편합니다.

## 쓰는 법
- 보내기: 유튜브 영상이나 웹 글에서 확장 버튼 → "영상노트로 보내기" → "노트 열기".
- 영상노트가 꺼져 있으면 "영상노트를 먼저 켜 주세요"라고 나옵니다.
- 구간 스크랩: 유튜브 영상 아래 "영상노트" 바에서 "구간 시작" → "구간 끝" → 메모(선택) → "스크랩 저장".
  단축키: Alt+S 시작, Alt+E 끝.
- 영상노트에서 그 영상의 노트를 열면 영상 아래에 "스크랩 구간"이 나오고, 누르면 그 구간부터 재생됩니다.
  (노트가 없는 영상의 스크랩은 저장만 되고, 그 영상을 영상노트로 보내면 보입니다.)

## 지우는 법
`chrome://extensions` 에서 "영상노트 보내기" 제거. 스크랩은 `data/clips.json` 에 남습니다.
